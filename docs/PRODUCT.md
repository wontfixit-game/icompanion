# Product vision — vs 新數碼暴龍

## Positioning

**icompanion / 相片怪獸工房** 對標「被人罵 UI 複雜、育成薄、對戰弱」的新數碼暴龍體驗。

我們贏在三件事：

1. **創作要超簡單、一定 thumb-friendly** — 一隻手指完成造怪，不逼玩家面對桌面級控制台。
2. **育成是遊戲本體** — 餵食／清潔／訓練／睡眠／失誤會真實影響進化與戰力，不是裝飾用按鈕。
3. **連線對戰是正餐** — 育成結果要能拿去跟人打，不是單機展示。

保留舊 MVP 的核心信念：**玩家擁有每一粒 pixel**；相片只是材料，不是 AI 自動出怪。

## Pain we refuse to copy

| 常見被罵點 | 我們的對策 |
|-----------|-----------|
| 介面像後台 / 按鈕海 | 手機優先單欄；底部大拇指區；一屏一事 |
| 育成無感 | 時間衰減、便便／生病、照顧失誤、進化條件清楚 |
| 造怪太難或太自動 | 3 步創作：材料 → 輕改 → 命名；進階畫筆藏起來 |
| 對戰與養成脫節 | 戰力直接吃育成數值；勝場影響進化 |

## Screen map (v10)

```
┌─────────────────────────────┐
│  頂欄：名字 / 階段 / 狀態    │
│                             │
│     大畫面房間 + 怪獸        │  ← 視覺主體
│                             │
│  狀態條（飽腹／心情／體力）   │
├─────────────────────────────┤
│  大拇指操作區（育成動作）     │  ← 64px+ 觸控
├─────────────────────────────┤
│  [育成]  [創作]  [對戰]      │  ← 底部 Tab
└─────────────────────────────┘
```

### 育成 Home
- 怪獸在房間活動；便便／肚子餓／想睡會自己出現
- 底部 6 個大鍵：餵食、玩耍、訓練、清潔、休息、探險
- 長按或次頁看詳細數值與進化條件

### 創作 Create（簡化）
1. **材料** — 相片 / 隨機 / 模板（大卡片選擇）
2. **微調** — 只留：筆／擦／ Undo／退地；五官拖放
3. **命名** — 確認出巢，進入育成

進階工具（填色桶、形狀、鏡像…）收在「進階」抽屉，不擋主流程。

### 對戰 Battle
- **練習戰** — 打 CPU，測育成成果
- **連線房** — 開房碼 / 入房碼，P2P 回合制對戰
- 出招：攻擊 / 特技 / 防禦（大按鈕）

## Raising model (Digimon-flavored)

- **階段**：幼體 → 成長期 → 成熟期 → 完全體
- **衰減**：離線／掛機會掉飽腹、心情；太久不清潔會生病
- **失誤**：餓太久、便便堆著、強迫訓練 → `careMistakes++`
- **訓練傾向**：力量 / 速度 / 智慧 累積，決定進化分支
- **進化**：滿足年齡 + 行動數 + 傾向 + 勝場 + 失誤上限

## Online battle (MVP net)

- 瀏覽器 P2P（PeerJS 公網 broker）+ 6 位房碼
- 主機同步回合狀態；斷線可回練習戰
- 之後可換自架 signalling，不改戰鬥規則層

## Out of scope for v10 slice

- 帳號系統 / 排位賽季
- 真實金錢課金
- 3D / 複雜動作遊戲手感
- 完整 Digimon 百科式進化樹（先做 4 階段 × 3 分支）
